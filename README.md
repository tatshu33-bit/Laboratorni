# Магазин Одягу - Flask Web Application

Веб-застосунок магазину одягу, створений з використанням Flask фреймворку.

## Опис проекту

Це повнофункціональний веб-застосунок інтернет-магазину одягу з наступними можливостями:
- Перегляд каталогу товарів
- Додавання товарів до кошика
- Управління кошиком (додавання, видалення, зміна кількості)
- Перегляд відгуків клієнтів
- Інформація про магазин, доставку та контакти

## Функціональність

### Реалізовані сторінки:

1. **Головна** (`/`) - Презентація магазину з рекомендованими товарами
2. **Каталог** (`/catalog`) - Повний каталог товарів
3. **Кошик** (`/cart`) - Управління кошиком покупок
4. **Про нас** (`/about`) - Інформація про магазин
5. **Відгуки** (`/reviews`) - Відгуки клієнтів та форма для залишення відгуку
6. **Контакти** (`/contacts`) - Контактна інформація та форма зворотнього зв'язку
7. **Доставка** (`/delivery`) - Інформація про доставку та оплату

### Основні можливості:

- ✅ Адаптивний дизайн для всіх пристроїв
- ✅ Функціональний кошик з можливістю:
  - Додавання товарів
  - Зміни кількості товарів
  - Видалення товарів
  - Перегляду загальної суми
- ✅ Використання Jinja2 для шаблонізації
- ✅ Навігаційне меню з підсвіткою активної сторінки
- ✅ Система повідомлень (flash messages)
- ✅ Лічильник товарів у кошику

## Встановлення та запуск

### Вимоги

- Python 3.8 або новіша версія
- pip (менеджер пакетів Python)

### Інструкція з встановлення

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/tatshu33-bit/Laboratorni.git
   cd Laboratorni
   ```

2. **Перейдіть на гілку laboratorn.3:**
   ```bash
   git checkout laboratorn.3
   ```

3. **Створіть віртуальне середовище (рекомендується):**
   ```bash
   python -m venv venv
   ```

4. **Активуйте віртуальне середовище:**
   - На Windows:
     ```bash
     venv\Scripts\activate
     ```
   - На macOS/Linux:
     ```bash
     source venv/bin/activate
     ```

5. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

### Запуск застосунку

1. **Запустіть Flask сервер:**
   ```bash
   python app.py
   ```

2. **Відкрийте браузер та перейдіть за адресою:**
   ```
   http://localhost:5000
   ```

3. **Зупинка сервера:**
   - Натисніть `Ctrl+C` в терміналі

## Технології

- **Backend:** Flask 3.0.0
- **Шаблонізатор:** Jinja2 3.1.2
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Стилізація:** Custom CSS з адаптивним дизайном
- **Session Management:** Flask Sessions

## Розробка

### Структура коду

- **app.py** - містить всі роути, обробники та логіку застосунку
- **templates/** - Jinja2 шаблони з наслідуванням від base.html
- **static/css/style.css** - всі стилі з адаптивним дизайном
- **static/js/main.js** - клієнтська логіка та інтерактивність

### Додавання нових товарів

Редагуйте змінну `PRODUCTS` у файлі `app.py`:

```python
PRODUCTS = [
    {
        'id': 1,
        'name': 'Назва товару',
        'category': 'Категорія',
        'price': 999.00,
        'image': 'image.jpg',
        'description': 'Опис товару'
    },
    # Додайте нові товари тут
]
```

### Налаштування

Основні налаштування можна змінити в `app.py`:
- `app.secret_key` - секретний ключ для сесій
- `app.run()` параметри - хост, порт, режим debug

## Особливості реалізації

1. **Організація коду** - відповідає стандартам Flask із розділенням статичних ресурсів та шаблонів
2. **Адаптивність** - використання CSS Grid та Media Queries для коректного відображення на всіх пристроях
3. **Кошик** - реалізовано через Flask sessions без бази даних
4. **Шаблонізація** - використання Jinja2 із базовим шаблоном та наслідуванням
5. **UX** - flash messages для зворотнього зв'язку з користувачем
