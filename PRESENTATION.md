# Презентація проєкту: Інтернет-магазин одягу

## 📋 Огляд проєкту

**Назва**: Laboratorni - Integrated Laboratory Applications  
**Тип**: Full-stack веб-застосунок для електронної комерції  
**Технології**: Python Flask, SQLite, Node.js, Express, HTML5, CSS3, JavaScript  
**Розробник**: Laboratory coursework project

---

## 🎯 Мета проєкту

Створення повнофункціонального інтернет-магазину одягу з:
- Зручним каталогом товарів
- Системою управління замовленнями
- Адміністративною панеллю
- RESTful API
- Responsive дизайном

---

## 🌟 Ключові можливості

### Для покупців:

#### 1. Каталог товарів 🛍️
- Перегляд товарів з фото, описом та цінами
- **Пошук** за назвою та описом товарів
- **Фільтрація**:
  - За категоріями (Сорочки, Джинси, Светри, тощо)
  - За діапазоном цін (min - max)
- Відображення наявності товару на складі
- Індикатори "Залишилось мало" та "Немає в наявності"

#### 2. Кошик покупок 🛒
- Додавання товарів до кошика
- Зміна кількості товарів
- Видалення товарів
- Автоматичний підрахунок загальної суми
- Збереження кошика в сесії

#### 3. Оформлення замовлень 📦
- Проста та зрозуміла форма оформлення
- Валідація всіх вхідних даних:
  - Email формат
  - Коректний номер телефону
  - Перевірка імені (тільки літери)
- Автоматичне створення/оновлення профілю клієнта
- Підтвердження замовлення з деталями

#### 4. Відстеження замовлень 📋
- Пошук замовлень за email адресою
- Перегляд статусу всіх замовлень
- Детальна інформація про замовлення:
  - Список товарів
  - Адреса доставки
  - Контактні дані
  - Часова шкала статусів
- 5 статусів: Очікується → Обробляється → Відправлено → Доставлено (або Скасовано)

#### 5. Відгуки ⭐
- Залишення відгуків про магазин
- Оцінка від 1 до 5 зірок
- Текстові коментарі
- Перегляд відгуків інших покупців

### Для адміністраторів:

#### 6. Адміністративна панель 🔧
- Безпечний вхід з аутентифікацією
- Управління товарами (CRUD):
  - Додавання нових товарів
  - Редагування існуючих
  - Видалення товарів
  - Контроль запасів
- Управління замовленнями:
  - Перегляд всіх замовлень
  - Зміна статусів
  - Перегляд деталей замовлення
- Управління клієнтами:
  - База даних клієнтів
  - Контактна інформація
  - Історія замовлень
- Управління відгуками:
  - Перегляд відгуків
  - Модерація відгуків

#### 7. REST API 🔌
- 10+ RESTful endpoints
- Swagger/OpenAPI документація
- JSON формат відповідей
- Підтримка CRUD операцій
- Health check endpoint

## 🏗️ Архітектура проєкту

### Backend (Python Flask)

```
app.py              - Головний застосунок Flask
├── Routes          - Веб-маршрути
│   ├── Public      - Головна, Каталог, Кошик, тощо
│   ├── Orders      - Оформлення, Відстеження
│   └── Admin       - Адмін панель
├── API Routes      - RESTful API endpoints
└── Authentication  - Система входу адміністратора

database.py         - Робота з БД
├── Connection      - Підключення до SQLite
├── Initialization  - Створення таблиць
├── Seeding         - Тестові дані
└── CRUD            - Операції з даними

validation.py       - Валідація та санітизація
├── Email           - Перевірка формату email
├── Phone           - Перевірка номера телефону
├── Sanitization    - Захист від XSS
└── Data validation - Перевірка всіх вхідних даних
```

### Database Schema (SQLite)

```
products            - Товари
├── id
├── name
├── category
├── price
├── description
├── stock
└── image

orders              - Замовлення
├── id
├── client_id
├── total_amount
├── status
├── created_at
└── updated_at

order_items         - Товари в замовленні
├── id
├── order_id
├── product_id
├── quantity
└── price

clients             - Клієнти
├── id
├── name
├── email
├── phone
├── address
└── created_at

feedback            - Відгуки
├── id
├── author
├── email
├── rating
├── text
└── date
```

### Frontend

```
templates/          - Jinja2 шаблони
├── base.html       - Базовий шаблон
├── index.html      - Головна сторінка
├── catalog.html    - Каталог з фільтрами
├── cart.html       - Кошик
├── checkout.html   - Оформлення
├── track_order.html - Відстеження
├── order_details.html - Деталі замовлення
├── reviews.html    - Відгуки
└── admin/          - Адмін панель

static/
├── css/
│   └── style.css   - Стилі (1300+ рядків)
└── js/
    └── main.js     - JavaScript логіка
```

### Node.js Resource Manager (Lab 6)

```
server.js           - Express сервер
public/
├── index.html      - HTML інтерфейс
├── styles.css      - Стилі
└── app.js          - Frontend логіка
```

## 🔒 Безпека

### Впроваджені заходи:

1. **XSS захист**
   - HTML санітизація всіх вхідних даних
   - Автоматичне екранування в Jinja2

2. **SQL Injection захист**
   - Параметризовані запити
   - Відсутність динамічного SQL

3. **Валідація даних**
   - Серверна валідація всіх форм
   - Перевірка типів та форматів
   - Обмеження довжини тексту

4. **Управління сесіями**
   - Безпечні секретні ключі
   - HTTP-only cookies
   - Автоматичне очищення

### Рекомендації для production:

- Використання HTTPS/SSL
- CSRF токени
- Rate limiting
- Хешування паролів
- Змінні оточення для credentials

- **Validation**: ~90 рядків
- **Всього**: ~4,000+ рядків коду

### База даних:

- **СУБД**: SQLite
- **Таблиць**: 5 (products, orders, order_items, clients, feedback)
- **Зв'язки**: Foreign keys, Cascades
- **Індекси**: Автоматичні primary keys

### API Endpoints:

**System**:
- `GET /api/health` - Health check
- `GET /api/docs` - Swagger документація

**Products**:
- `GET /api/products` - Список товарів
- `POST /api/products` - Створити товар
- `PUT /api/products/<id>` - Оновити товар
- `DELETE /api/products/<id>` - Видалити товар

**Orders & Feedback**:
- `GET /api/orders` - Список замовлень
- `GET /api/feedback` - Список відгуків
- `POST /api/feedback` - Додати відгук

## 🚀 Демонстрація

### Основні сценарії використання:

1. **Пошук товару**
   ```
   Користувач → Каталог → Пошук "светр" 
   → Фільтр ціни 500-1500 → Результати
   ```

2. **Покупка**
   ```
   Товар → Додати до кошика → Кошик 
   → Оформити → Заповнити форму → Підтвердження
   ```

3. **Відстеження**
   ```
   Мої замовлення → Ввести email 
   → Список замовлень → Деталі → Статус
   ```

4. **Адмін робота**
   ```
   /admin → Вхід → Управління товарами 
   → Додати/Редагувати → Збереження
   ```
